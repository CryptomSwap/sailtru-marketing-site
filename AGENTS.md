# AGENTS.md

## Blender modelling

Blender modelling runs headless via `node scripts/run-blender-model.mjs`. It runs `scripts/build-sailtru-boat-blender.py` and exports a web-ready `.glb` to `public/models/journey/sailtru-logo-boat.glb` (plus an editable `.blend` next to it and a preview render in `artifacts/renders/`). Generated outputs are not committed.

`scripts/blender-locator.mjs` finds Blender: `BLENDER_PATH` first, then the newest Windows install under `C:\Program Files\Blender Foundation`, then the same install seen from WSL at `/mnt/c/Program Files/Blender Foundation/*/blender.exe`, then `blender` on PATH. Under WSL, paths passed to `blender.exe` are translated with `wslpath -w`.

## Homepage: the 3D harbor is the canonical track

The homepage (`src/app/[locale]/page.tsx`) is built on the React Three Fiber 3D harbor scene (`src/components/harbor/three/harbor-scene.tsx`, loaded lazily by `src/components/harbor/harbor-story.tsx`). Always build on that scene. Do not restart from the 2D SVG harbor or from older prototypes. `/[locale]/preview/harbor-3d` (noindex) is the isolated review route for the same scene.

- The 2D SVG harbor (`src/components/harbor/harbor-world.tsx`) is kept only as the fallback for `prefers-reduced-motion`, no WebGL2, WebGL context loss, asset-load failure and render errors. It is server-rendered first so there is no layout shift; the stage exposes `data-harbor3d="loading|ready|fallback|error"`. Do not extend it with features the 3D scene does not have.
- One progression: `StoryCues` in `story-model.ts` gives every supporting line a cue; the narrative cards (one headline, one active line), demonstration cards, context labels/badges and scene actions all derive from it, so reverse scroll, jumps and resizes land on the same state. Narrative cards live in one sticky deck and cross-fade; demonstration cards reserve their space before content appears. Provider logos are verbatim files in `public/images/providers/` (sources in `docs/harbor-3d-v2/logo-sources.md`).
- One loop and one camera owner: `HarborStory`'s requestAnimationFrame loop owns scroll smoothing and calls `stage.frame()` (the canvas uses `frameloop="never"`). Scroll picks camera viewpoints (`CameraRig3D` / `HarborLayout3D` in `story-model.ts`), the pointer adds a smoothed, restrained offset on top, and an ambient clock drives bobbing boats, water, gulls, clouds and the turning lighthouse lamp. Text, reports and controls stay crisp HTML overlays; leaders and tags follow projected 3D anchors. On phones the stacked layout keeps normal document flow: a live opening view plus a 3D still per chapter.
- 3D props (boats and hulls, buoy, lighthouse, crane, workshop and houses, docks/jetty/bollards, rocks, islets, palms, clouds, gulls) are Blender-modelled `.glb` files under `public/models/harbor/`, made through the Blender pipeline above: `node scripts/run-blender-harbor-assets.mjs` regenerates the harbor set (`scripts/build-harbor-assets-blender.py`), `node scripts/run-blender-model.mjs` the detailed SailTru boat. They are Draco-compressed and loaded with drei `useGLTF` and the self-hosted decoder in `public/draco/` (no CDN). Prefer improving a Blender model over adding box/cylinder primitives in code. Keep each GLB well under 400 KB and the set small; commit the `.glb` files, not `.blend` files or renders (`artifacts/`).
- Look: warm ivory paper, charcoal ink outlines (inverted hulls), toon shading, soft fog and a subtle paper grain; cards use a 1.5px ink outline and hard offset shadows (narrative 14px/8px, demonstration 14px/6px, context labels 10px/4px), no soft floating shadows or glass. Cobalt only for active elements: SailTru's boat, the active finding (F01), the route, the active crane hook, the shipped change and the primary action. Metaphors stay fixed: cobalt boat = SailTru's investigation and delivery journey, the town and quay = the client's business, neutral provider boats with platform badges = the search and AI platforms being examined (never doing SailTru's work), buoys = investigation areas or findings, report = priorities, route = the recommended next action, shipyard (crane, workshop) = implementation. The palette lives in `src/components/harbor/harbor-theme.ts` (`HarborTheme`) and the matching CSS custom properties on `.harbor` in `harbor.css`.
- The cobalt above-the-fold hero (`src/components/sections/home-v2/home-hero.tsx` and the home-v2 styles) opens the homepage inside HarborStory. Its 180svh entrance uses the existing scroll/frame loop and the same Blender ship; keep the physical-left approach, card dissolve, reverse-scroll behavior, and stacked mobile/reduced-motion fallback.
